# Historical artifacts

- `root-tools/`: one-off frontend extraction/patch scripts, store refactoring script, and captured search results.
- `test-results/`: previous generated test results preserved as snapshots.
- Backend source patch scripts are retained separately in `../backend/archive/patches/`.

These files preserve project history. They are not part of the application's build or automated tests. Old scripts retain their original assumptions and may no longer run against current source; review them before reuse.
