# Healix Mobile Development Guidelines

1. **Expo Versioning:**
   - Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

2. **Healix Design System (MANDATORY):**
   - All mobile screens and components MUST strictly follow the design tokens and layout principles in `../HEALIX_DESIGN_SYSTEM.md`.
   - Use tokens from `src/theme.ts` (`COLORS`, `SPACING`, `RADIUS`, `TYPOGRAPHY`).
   - Never invent arbitrary colors or layout metrics.
